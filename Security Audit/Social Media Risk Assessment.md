# Social Media Risk Assessment

A social media organization recently experienced a major data breach that exposed customers' personal information. In response, leadership wants to strengthen their network security to prevent similar incidents in the future. During a review of the environment, the security team identified several major vulnerabilities that could allow attackers to gain access again. As the analyst assigned to this case, my responsibility is to assess these weaknesses and recommend network hardening methods the organization should adopt.

# Risk Assessment Report

Network's Vulnerabilities:

> 1. The organization's employees share passwords
>
> 2. The admin password for the database is set to the default
>
> 3. The firewalls do not have rules in place to filter incoming/ outgoing traffic
>
> 4. Multifactor authentication is not used

**Part 1: Select hardening tools and methods to implement**

The following methods will help address the organization's vulnerabilities:

**Password Policies** - Used to prevent attackers from easily guessing user passwords by enforcing certain rules regarding passwords. This can include password length, requiring certain characters, and adding a disclaimer to discourage password sharing.

**Multifactor Authentication** - A security measure that helps protect against brute-force attacks by requiring users to verify their identity. Some methods include a pin number, badge, one-time password, and more.

**Firewall Maintenance** - This includes checking and updating security configurations regularly to stay ahead of potential threats.

**Penetration Testing** - These are simulated attacks that help identify vulnerabilities in systems and help security teams protect and prevent against potential attacks.

**Part 2: Explain your recommendations**

Creating a password policy for the company will make it more difficult for threat actors to access the network. Increasing password complexity, requiring more frequent password updates, and not allowing people to reuse passwords will add more barriers for malicious actors. Additionally, suspending accounts after a certain number of login attempts can prevent brute-force attacks.

Enforcing multifactor authentication adds another layer of security, reducing the likelihood that threat actors will gain unauthorized access to the network. It also discourages sharing passwords because additional authentication is required to gain access to the network.

Firewalls should be maintained regularly to ensure their rules reflect the most up-to-date standards for network traffic. Traffic from suspicious sources should be on a deny list. Rules should be updated whenever a security event occurs to protect against future attacks.

The network should be tested for vulnerabilities frequently to prevent potential attacks. Regular penetration testing helps the organization identify weaknesses before threat actors can exploit them. These simulated attacks validate whether new security controls are functioning as intended and can reveal any overlooked gaps in the environment.
